This directory holds the sample data sets used by the FST4 exemplar
demos and by the fst4 CLI golden-test scenarios (see tests/manifest.tsv).
Since FST4 4.0 the data sets are bundled
with the distribution; no separate download is needed.

Run the executables from the distribution root so that the relative
data/ paths resolve.

These data sets are third-party research data and are NOT covered by the
FST4 copyright: each carries its own origin and terms. See NOTICE in this
directory for the full attribution -- creators, citation, licence, and the
modifications FST4 applied -- and the header of each data file, which repeats
the same information for that file alone (exception: the .csv files carry no
in-file header -- the CSV format has no comment syntax; NOTICE covers them).

See https://fst.utia.cz for more on the toolbox.
